# 2027 한울타리 FC 유니폼 투표

후보 17종을 **이상형 월드컵**으로 고른다.
비슷한 디자인끼리 먼저 붙여서, 같은 계열이 표를 나눠 먹고 둘 다 떨어지는 일을 막았다.

```
예선 1경기  →  16강 8경기  →  8강 4  →  4강 2  →  결승 1   = 한 사람당 16번 선택
```

## 점수

회원 한 사람의 선택을 **단계별 진출 점수**로 환산해 전원 합산한다.

| 단계 | 승리 시 | 왜 |
|---|---|---|
| 예선 | **0점** | 16강 자리를 채우는 경기다. 점수를 주면 예선을 거친 디자인만 최대 점수가 높아져 불공평해진다 |
| 16강 | 2점 | |
| 8강 | 3점 | |
| 4강 | 5점 | |
| 결승(우승) | 8점 | 우승에 가중치를 둔다 |

한 사람이 한 디자인에 줄 수 있는 최대는 **18점**이다.
집계는 점수 → 우승표 수 순으로 정렬한다.

## 폴더

```
kits.js            후보 17종 · 대진표 · 점수표   ← 여기만 고치면 된다
server.js          API + 정적 서빙
public/            index.html · app.js · style.css · results.html · kits/*.jpg
ROSTER.txt         명부 이름 (환경변수에 넣을 값, 저장소에 올리지 않는다)
```

## 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `DATABASE_URL` | ○ | Postgres 연결 문자열. 없으면 메모리에만 남고 재시작 시 사라진다 |
| `ADMIN_KEY` | ○ | 집계 화면(`/results.html`) 열쇠. 아무도 못 맞출 문자열로 |
| `ROSTER` | △ | 쉼표로 구분한 회원 이름. 넣으면 명부에 없는 이름은 투표가 막힌다 |
| `VOTE_OPEN` | | `false`로 두면 투표 마감 |

**`ROSTER`는 코드에 넣지 않는다.** 저장소가 공개돼도 명부가 따라 나가지 않게 하기 위해서다.
값은 `ROSTER.txt`에 있다. **이 파일은 git에 올리지 않는다** (`.gitignore`에 있다).

> 동명이인 주의 — 이름이 투표자 식별자다. 같은 이름이 둘이면 뒤에 투표한 사람이
> 앞사람을 덮어쓴다. 동명이인이 있으면 `홍길동A` / `홍길동B`처럼 갈라서 `ROSTER`에 넣는다.

## 배포 (Render)

Render는 **Git 저장소**에서만 배포한다. 순서는 이렇다.

1. **이 `vote/` 폴더만** 새 저장소로 만든다. 상위 `Chongmu` 폴더에서 `git init`을 하면
   회계 장부와 명부가 통째로 올라간다. **반드시 `vote/` 안에서 한다.**
   ```bash
   cd vote
   git init && git add . && git commit -m "유니폼 투표"
   ```
2. GitHub에 **비공개(private)** 저장소를 만들고 push 한다.
3. Render → New → Web Service → 그 저장소 선택
   - Runtime `Node` · Build `npm install` · Start `npm start`
4. Render → New → Postgres 를 만들고, 그 **Internal Database URL**을
   웹 서비스의 `DATABASE_URL` 환경변수에 넣는다.
5. `ADMIN_KEY`, `ROSTER` 환경변수를 넣는다. (`ROSTER` 값은 `ROSTER.txt`)
6. 배포되면 `https://<이름>.onrender.com` 이 나온다. 이 링크를 공지방에 올린다.
   집계는 `https://<이름>.onrender.com/results.html` — **총무만 본다.**

### 알아둘 것

- **무료 플랜은 15분 놀면 잠든다.** 다시 열 때 30초쯤 걸린다. 57명이 몰리는 투표라면
  유료(Starter)로 올리거나, 공지에 "처음 열 때 조금 느릴 수 있습니다"를 적어두면 된다.
- **무료 Postgres는 30일 뒤 삭제된다.** 2주짜리 투표에는 충분하지만,
  투표가 끝나면 집계 화면을 캡처해 두는 편이 안전하다.

## 로컬에서 보기

```bash
cd vote && npm install
ADMIN_KEY=test node server.js     # http://localhost:3000
```

`DATABASE_URL` 없이 띄우면 메모리에 저장되고 경고가 뜬다. 확인용으로는 충분하다.

## 이미지를 바꾸면

`public/kits/*.jpg`를 교체한 뒤 **`public/app.js`의 `V` 값을 올린다.**
안 올리면 이미 들어온 회원의 브라우저가 옛 그림을 계속 보여준다.
