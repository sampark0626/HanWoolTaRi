# 2027 한울타리 FC 유니폼 투표

후보를 늘어놓고 **마음에 드는 것을 골라 담는다.** 고른 순서가 곧 순위다.

> 대진표(이상형 월드컵)는 걷어냈다 (총무 확인 2026-10-09).
> 붙는 상대에 따라 결과가 흔들려서 **디자인끼리 공정하게 비교가 안 됐다.**
> 1라운드에서 센 디자인끼리 만나면 둘 중 하나는 거기서 끝난다.

## 점수

| 순위 | 점수 (PICKS=3) |
|---|---|
| 1순위 | 3점 |
| 2순위 | 2점 |
| 3순위 | 1점 |

전원 합산해서 점수 → 1순위 표 수로 정렬한다.

## 두 번에 나눠 한다

1. **1차** — 17종에서 3개. 상위 5종이 결선 후보가 된다.
2. **결선** — 환경변수에 `SHORTLIST`(후보 id, 쉼표 구분)와 `PICKS=1`을 넣으면
   **같은 주소가 결선 투표로 바뀐다.** 집계 화면이 복사할 id를 찍어준다.
   표를 비우려면 `POST /api/reset?key=<ADMIN_KEY>&confirm=yes`.

## 폴더

```
kits.js            후보 17종 · 대진표 · 점수표   ← 여기만 고치면 된다
server.js          API + 정적 서빙
public/            index.html · app.js · style.css · results.html · kits/*.jpg
ROSTER.txt         명부 이름 (환경변수에 넣을 값, 저장소에 올리지 않는다)
```

## 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `DATABASE_URL` | ○ | Postgres 연결 문자열. 없으면 메모리에만 남고 재시작 시 사라진다 |
| `ADMIN_KEY` | ○ | 집계 화면(`/results.html`) 열쇠. 아무도 못 맞출 문자열로 |
| `ROSTER` | △ | 쉼표로 구분한 회원 이름. 투표 화면에서 **목록으로 고른다** |
| `ROSTER_LABELS` | | 화면에 쓸 이름을 따로 줄 때. `최지훈S=최지훈 (S),최지훈B=최지훈 (B)` |
| `VOTE_OPEN` | | `false`로 두면 투표 마감 |
| `PICKS` | | 한 사람이 고르는 개수. 기본 3. 결선에서는 1 |
| `SHORTLIST` | | 결선 후보 id(쉼표). 넣으면 그 후보만 나오고 화면이 「결선 투표」가 된다 |
| `ROUND_NAME` | | 화면 맨 위 문구. 안 넣으면 1차는 「2027 시즌」, 결선은 「결선 투표」 |
| `AUTH` `AUTH_SALT` | △ | 본인 확인(전화 뒷 4자리). `scripts/make_auth.py`가 만든 `AUTH.txt`에서 복사 |

**`ROSTER`는 코드에 넣지 않는다.** 저장소가 공개돼도 명부가 따라 나가지 않게 하기 위해서다.
값은 `ROSTER.txt`에 있다. **이 파일은 git에 올리지 않는다** (`.gitignore`에 있다).

> 동명이인 주의 — 이름이 투표자 식별자다. 같은 이름이 둘이면 뒤에 투표한 사람이
> 앞사람을 덮어쓴다. 동명이인이 있으면 `홍길동A` / `홍길동B`처럼 갈라서 `ROSTER`에 넣는다.
>
> 이름은 **치는 게 아니라 목록에서 고른다.** 쳐서 넣게 하면 동명이인이 자기 이름을
> 그대로 쳤다가 "명부에 없는 이름"으로 거부당한다. 50여 명이면 고르는 쪽이 빠르다.
>
> 구분자(`S`/`B`, `(S)`/`(B)`)는 **명부용이지 옷에 박을 글자가 아니다.**
> 유니폼 마킹에는 구분자를 뗀 본명이 찍힌다.

### 남은 설정 한 가지 — `DATABASE_URL`

DB 비밀번호는 API로 안 나와서 **직접 한 번 넣어야 한다.**
넣기 전까지는 투표가 막혀 있다 (표를 조용히 잃는 것보다 낫다).

1. DB 대시보드 → **Internal Database URL** 복사
2. 서비스 대시보드 → Environment → Add Environment Variable
   - Key `DATABASE_URL` / Value 붙여넣기
3. 저장하면 자동으로 다시 뜬다. 1~2분 뒤 투표 링크를 열어 시작 버튼이 눌리면 완료.

## 로컬에서 보기

```bash
cd vote && npm install
ADMIN_KEY=test node server.js     # http://localhost:3000
```

`DATABASE_URL` 없이 띄우면 메모리에 저장되고 경고가 뜬다. 확인용으로는 충분하다.

## 가격은 보여주지 않는다

가격이 보이면 디자인이 아니라 가격으로 고르게 된다 (총무 확인 2026-10-09).
화면에서 숨기는 게 아니라 **`/api/config`에서 아예 빼서** 페이지 소스에도 남지 않는다.
업체명도 같은 이유로 빼두었다. 집계 화면(총무용)에는 그대로 나온다.

## 본인 확인

다른 사람 이름을 골라 투표하는 걸 막는다. **전화번호 뒷 4자리**를 묻는다.

**연락처 원본은 서버에 없다.** `scripts/make_auth.py`가 뒷 4자리를 소금과 함께
해시해서 그 결과만 만든다. 서버는 대조만 할 수 있고 번호를 복원하지 못한다.
규정집의 「개인정보 반출 금지」를 지키면서 확인만 하기 위한 방식이다.

```
uv run --python 3.12 python scripts/make_auth.py     # → vote/AUTH.txt
```

`AUTH.txt`의 `AUTH_SALT`, `AUTH` 두 값을 Render 환경변수에 넣는다.
**이 파일은 git에 올라가지 않는다.**

**틀렸다고 막지 않는다** (총무 확인 2026-10-09). 제출할 때 한 번 되물어 오타를 잡아주고,
그래도 다르면 **그대로 받고 번호만 적어 둔다.** 집계 화면이 그 명단을 따로 보여준다.

- **맞는 번호는 저장하지 않는다.** 틀린 것만 남긴다 — 총무가 확인해야 하는 건 그것뿐이고,
  맞는 번호를 DB에 쌓으면 해시로 감춘 의미가 없어진다.
- 되묻는 것 자체가 「맞다/틀리다」를 알려주는 창구다. **5번 되물으면 그만 묻고 그냥 받는다.**
  안 그러면 1만 번 넣어보고 남의 번호 뒷자리를 알아낼 수 있다. (10분 뒤 다시 열린다 —
  시간을 들이면 뚫리므로, 작정한 공격을 막는 장치는 아니다.)
- 연락처가 없는 회원은 확인할 방법이 없어 **아무 4자리나 통과한다.**
  `make_auth.py`가 그 명단을 찍어준다. 번호를 받아 `members.csv`에 채우고
  다시 돌리면 막힌다.
- 소금을 바꾸면 해시를 전부 다시 만들어야 한다.
