# 2027 한울타리 FC 유니폼 투표

후보 17종을 **이상형 월드컵**으로 고른다.
비슷한 디자인끼리 먼저 붙여서, 같은 계열이 표를 나눠 먹고 둘 다 떨어지는 일을 막았다.

```
예선 1경기  →  16강 8경기  →  8강 4  →  4강 2  →  결승 1   = 한 사람당 16번 선택
```

## 점수

회원 한 사람의 선택을 **단계별 진출 점수**로 환산해 전원 합산한다.

| 단계 | 승리 시 | 왜 |
|---|---|---|
| 예선 | **0점** | 16강 자리를 채우는 경기다. 점수를 주면 예선을 거친 디자인만 최대 점수가 높아져 불공평해진다 |
| 16강 | 2점 | |
| 8강 | 3점 | |
| 4강 | 5점 | |
| 결승(우승) | 8점 | 우승에 가중치를 둔다 |

한 사람이 한 디자인에 줄 수 있는 최대는 **18점**이다.
집계는 점수 → 우승표 수 순으로 정렬한다.

## 폴더

```
kits.js            후보 17종 · 대진표 · 점수표   ← 여기만 고치면 된다
server.js          API + 정적 서빙
public/            index.html · app.js · style.css · results.html · kits/*.jpg
ROSTER.txt         명부 이름 (환경변수에 넣을 값, 저장소에 올리지 않는다)
```

## 환경변수

| 이름 | 필수 | 설명 |
|---|---|---|
| `DATABASE_URL` | ○ | Postgres 연결 문자열. 없으면 메모리에만 남고 재시작 시 사라진다 |
| `ADMIN_KEY` | ○ | 집계 화면(`/results.html`) 열쇠. 아무도 못 맞출 문자열로 |
| `ROSTER` | △ | 쉼표로 구분한 회원 이름. 넣으면 명부에 없는 이름은 투표가 막힌다 |
| `VOTE_OPEN` | | `false`로 두면 투표 마감 |

**`ROSTER`는 코드에 넣지 않는다.** 저장소가 공개돼도 명부가 따라 나가지 않게 하기 위해서다.
값은 `ROSTER.txt`에 있다. **이 파일은 git에 올리지 않는다** (`.gitignore`에 있다).

> 동명이인 주의 — 이름이 투표자 식별자다. 같은 이름이 둘이면 뒤에 투표한 사람이
> 앞사람을 덮어쓴다. 동명이인이 있으면 `홍길동A` / `홍길동B`처럼 갈라서 `ROSTER`에 넣는다.

### 남은 설정 한 가지 — `DATABASE_URL`

DB 비밀번호는 API로 안 나와서 **직접 한 번 넣어야 한다.**
넣기 전까지는 투표가 막혀 있다 (표를 조용히 잃는 것보다 낫다).

1. DB 대시보드 → **Internal Database URL** 복사
2. 서비스 대시보드 → Environment → Add Environment Variable
   - Key `DATABASE_URL` / Value 붙여넣기
3. 저장하면 자동으로 다시 뜬다. 1~2분 뒤 투표 링크를 열어 시작 버튼이 눌리면 완료.

## 로컬에서 보기

```bash
cd vote && npm install
ADMIN_KEY=test node server.js     # http://localhost:3000
```

`DATABASE_URL` 없이 띄우면 메모리에 저장되고 경고가 뜬다. 확인용으로는 충분하다.

## 가격은 보여주지 않는다

가격이 보이면 디자인이 아니라 가격으로 고르게 된다 (총무 확인 2026-10-09).
화면에서 숨기는 게 아니라 **`/api/config`에서 아예 빼서** 페이지 소스에도 남지 않는다.
업체명도 같은 이유로 빼두었다. 집계 화면(총무용)에는 그대로 나온다.
